# Placeholder Icons

This folder should contain the following icon files:
- icon16.png (16x16 pixels)
- icon48.png (48x48 pixels)
- icon128.png (128x128 pixels)

For development, you can use any PNG images of the appropriate sizes.
For production, create proper branded icons.

## Quick Development Setup

You can generate simple placeholder icons using ImageMagick:

```bash
# Install ImageMagick if needed
# macOS: brew install imagemagick

# Generate simple colored squares as placeholders
convert -size 16x16 xc:#4F46E5 icon16.png
convert -size 48x48 xc:#4F46E5 icon48.png
convert -size 128x128 xc:#4F46E5 icon128.png
```

Or download free icons from:
- https://icons8.com
- https://flaticon.com
